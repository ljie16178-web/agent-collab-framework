# 去AI味.skill — AI写作风格提炼工具

## 定位

本skill不生成"数字分身"，而是生成"**写作风格指南**"。

目标：让AI输出的文字具有**人类写作的温度、节奏和个性**，而不是机器填充的模板感。

**核心哲学**：观察、提炼、参考——不是制定法律，而是建立语感。

---

## 触发条件

当用户说以下内容时启动：
- `/de-ai` 或 `/去AI味`
- "帮我去AI味"
- "分析我的写作风格"
- "生成去AI味指南"
- "把这段话改得不像AI写的"

## 核心原则（Anti-AI Writing Principles）

### 底层逻辑

AI写作有**三大病症**：

| 病症 | 症状 | 治法 |
|------|------|------|
| **完整癖** | 总想覆盖所有角度，"首先...其次...最后..." | 学习**跳跃**——敢于省略过渡，直接切入 |
| **安全癖** | 大量模糊限定词，"可能""大概""一定程度" | 学习**笃定**——有判断就说判断，加限定词要精确 |
| **中性癖** | 回避强烈态度，永远"两面都有道理" | 学习**立场**——可以不同意，可以批评，但要诚实 |

### 五条弹性规则

> **弹性原则**：以下所有规则都是"通常如此"的基准，例外时灵活处理。

**规则一：结论先行，论证紧随**
- AI习惯：铺垫三段再出结论
- 你的写法：开篇即判断，后接支撑
- 基准："火电利用小时下降是确定的，但量级因方法差异而异。"

**规则二：短句优先，长句有目的**
- AI习惯：用从句连接词堆砌长句，显得"正式"
- 你的写法：短句为主，长句仅在递进或对比时使用
- 基准：用句号切断，让节奏呼吸

**规则三：动词要具体，不要抽象**
- AI习惯："进行分析""进行讨论""发挥重要作用"
- 你的写法：找具体动词——"挤压""重构""撬动""指向"
- 基准：每个动词都能在脑中产生画面

**规则四：主动承认局限**
- AI习惯：隐藏假设和数据问题，只报显著结果
- 你的写法：主动标注"近似校准而非精确拟合"
- 基准：让读者知道边界在哪，而不是被模糊带过

**规则五：留白比说满更可信**
- AI习惯：把所有角度都覆盖，不留遗憾
- 你的写法：可以用问句结尾，或者明确说"这一问题仍有待深入"
- 基准：空白处体现思考的诚实

## 流程一：从文本样本提炼风格（/de-ai）

### 输入

用户提供文本样本（论文/报告/聊天记录/任何文字），或指定已有文件路径。

### Step 1：收集样本

确认以下信息：
1. **写作类型**：论文写作 / 报告写作 / 日常表达 / 全部都要
2. **样本来源**：粘贴文本 / 上传文件 / 指定路径 / 多个来源
3. **目标读者**：学术审稿人 / 领导 / 同事 / 朋友 / 不限

### Step 2：分析维度

从样本中提取以下特征：

```
【词汇层】
- 高频动词（具体 vs 抽象）
- 语气词偏好（"显然""其实""这意味着"）
- 禁用词（从不使用的AI高频词）
- 专业术语密度

【句式层】
- 平均句长
- 短句 vs 长句比例
- 连接词偏好（AI爱"因此""然而"，你爱什么？）
- 主动语态 vs 被动语态比例

【结构层】
- 开头方式（结论先行？还是背景引入？）
- 段落组织逻辑
- 结尾方式（总结？留白？反问？）
- 表格/图表的使用比例

【修辞层】
- 比喻使用（有还是没有？什么样的比喻？）
- 批判性表达（直接 vs 委婉）
- 情绪色彩（有温度 vs 中立）

【不确定性标注】
- 如何标注不确定性？
- "可能"？"大约"？"方向一致"？
- 什么情况下会主动暴露局限？
```

### Step 3：生成风格指南

输出结构：

```markdown
# {名字}的写作风格指南

## 核心标签（3-5个）
用3-5个词概括整体风格。

## 词汇偏好
### 推荐词（你常用的具体动词）
### 禁用词（你不用的AI高频词）

## 句式节奏
### 基准句长
### 连接词偏好
### 典型句式模板

## 结构习惯
### 开头模式
### 段落过渡方式
### 结尾方式

## 不确定性标注规则
### 确定时的表达
### 不确定时的表达
### 主动暴露局限的场景

## 去AI味检查清单
写完后自查：
- [ ] 结论是否在开头？
- [ ] 有没有保留跳跃/省略？
- [ ] 动词是否具体可画面化？
- [ ] 有没有主动承认局限？
- [ ] 节奏是呼吸感还是机器感？
```

## 流程二：直接去AI味（快速模式）

### 触发

用户直接贴一段文字或文件路径，说"去AI味"。

### 处理

1. 读取文本
2. 应用风格指南中的规则（如已建立）
3. 输出修改后的文本，并说明改了什么

### 修改原则

```
减：
- 删除所有"首先""其次""最后"
- 删除所有"显而易见""不难发现""值得注意的是"
- 删除所有"具有重要意义""产生深远影响"
- 缩短过长句子（>40字的拆开）
- 删除过度连接的"因此""然而""与此同时"

改：
- "这说明" → "这意味着" 或 "这指向"
- "增强/提升/改善" → 具体动词
- "可能/大概/一定程度" → 精确限定或删除
- 被动语态 → 主动语态

加：
- 短句插入，打破AI的均匀节奏
- 必要时加一句反问或留白
- 主动暴露局限的标注
```

---

## 风格指南的维护

### 追加样本
当用户提供新的文本样本时：
1. 读取现有风格指南
2. 分析增量样本
3. 对比是否有新特征
4. 更新指南（只增不覆盖）

### 纠正
当用户说"我不会这样写"时：
1. 识别被否定的表达方式
2. 在禁用词列表中追加
3. 保持弹性，不因此推翻整体框架
