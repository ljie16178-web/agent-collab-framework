# 刘杰的写作风格指南

> 本指南基于刘杰多篇对话分析文本（论文写作、报告写作、思维分析）提炼生成。
> **弹性参考，以此为基准**——不是法律，是语感锚点。

---

## 核心标签（5个）

```
批判性精确 · 物理直觉 · 主动诚实 · 短句节奏 · 结论先行
```

---

## 词汇偏好

### 推荐词（具象化、有画面感）

| AI爱用 | 你倾向用 | 为什么 |
|---------|---------|--------|
| 影响/作用 | **挤压**、**重构**、**撬动**、**锁死**、**质变** | 动词能产生物理画面 |
| 说明/表明 | **意味着**、**指向**、**倒果为因** | 更精确地表达因果推断的局限 |
| 重要/显著 | **结构性**、**方向一致**、**量级稳健** | 避免"显著"这种统计黑话 |
| 减少工时 | **缩短劳动时间** | 更直接，但你会批判这种DID结论 |

### 禁用词（AI高频，你几乎不用）

```
❌ 首先、其次、最后（系列连接词）
❌ 显而易见、不难发现、显然
❌ 值得我们深入探讨、具有重要意义
❌ 随着社会的不断发展、经济的持续增长
❌ 本文创新性地提出、首次系统地
❌ 这说明、这表明 → 替换为"这意味着""这指向"
❌ 增强、提升、改善 → 替换为具体动词
❌ 可能、大概、一定程度上 → 要么删，要么精确化
```

### 语气词与态度标记

```
常用：
  - "倒果为因""逻辑跳步""自欺欺人"（直接批判）
  - "这在物理上不可成立"（极端否定）
  - "近似校准而非精确拟合"（精确自我标注）
  - "方向确定，但量级因方法差异而异"
  - "质变"（形容临界点突破）

少用/不用：
  - "我觉得"（你的判断本身就是事实陈述）
  - "有趣的是"（你认为有趣不需要声明）
  - 表情符号和感叹号（除非极端情绪）
```

## 句式节奏

### 基准句长

```
目标：单句平均 15-25 字
上限：单句不超过 40 字（超过就拆开）
下限：单句不低于 5 字（低于5字除非是排比或反问）
```

### 连接词偏好（你用的 vs AI爱的）

| AI爱用 | 你倾向用 |
|---------|---------|
| 因此、所以、于是 | **但**、**这意味着**、**换言之** |
| 然而、但是 | **问题在于**、**致命的是** |
| 同时、与此同时 | **并且**、**且**、直接并列 |
| 综上所述、总之 | **核心结论是**、**换句话说** |

### 典型句式模板

```
1. 结论先行句：
   "[核心判断]。[支撑/解释/数据来源]。"

2. 精确不确定性句：
   "[结论]是确定的，但[量/范围]因[原因]而异。"

3. 局限暴露句：
   "[方法/数据局限]；这是[约束来源]而非[方法缺陷]。"

4. 批判句：
   "[表述]是[形容词，如：倒果为因的/逻辑跳步的/自欺欺人的]。"

5. 反问收束句：
   "[反问句本身？]"（不需要回答，震颤留白）
```

## 结构习惯

### 开头模式

**你的开头是"判断在前"**：
```
❌ AI式： "近年来，随着......的发展，......成为重要议题。"
✅ 你的式： "[直接判断]。[背景/来源]。"
```

示例：
> "DID隐含的'无摩擦流动'假设，在电力系统物理约束下完全破产。"（你的风格）
vs
> "双重差分法（DID）作为一种政策评估方法，近年来被广泛应用于......"（AI风格）

### 段落内部结构

```
你的模式：判断 → 支撑 → 例子/数据 → 可选的局限性
每段只做一件事
段与段之间靠逻辑承接，不靠连接词
```

### 结尾方式

| 场景 | 你的结尾方式 |
|------|------------|
| 学术论文 | 主动声明局限 + 方向判断 + 精确不确定性 |
| 市场报告 | 核心结论 + 适用情景 + 风险边界 |
| 批判分析 | 一句话致命判断 + 可选的震颤反问 |
| 一般论述 | 核心观点重述 + 开放性思考 |

## 不确定性标注规则

### 你对确定性的精确分级

| 确定性程度 | 你的表达方式 |
|-----------|------------|
| **极高**（物理/数学可证） | "在物理上不成立""数学上等价于" |
| **高**（方向确定，量级可靠） | "方向一致，量级因方法差异而异" |
| **中**（方向判断可靠） | "提示""指向""可能意味着" |
| **低**（仅作为假设提出） | "如果……那么……" + "需要进一步验证" |
| **未知** | "这一问题仍有待深入""目前无法判断" |

### 主动暴露局限的场景

```
1. 数据粗糙时：  "月度数据过于粗糙，无法捕捉日内峰谷；这是数据约束而非模型缺陷。"
2. 方法局限时：  "22%的预测精度，在G=27的渐近条件下不可信。"
3. 假设不可验证时："参数外推依赖不可直接检验的假设。"
4. 结论谨慎时：  "模型的逻辑洞察是强大的，但精确数值预测须被视为情景模拟。"
```

## 去AI味检查清单

**写完自查**（每项 Y/N）：

```
【结构】
[ ] 结论是否在前三句话内出现？
[ ] 每段是否只讨论一个核心点？
[ ] 是否有跳跃/省略（而不总是平滑过渡）？

【词汇】
[ ] 是否所有动词都能产生物理画面？
[ ] 有没有出现禁用词？（特别是"首先""因此""显然"）
[ ] 名词是否过于抽象？（"因素""作用""影响"）

【句式】
[ ] 有没有超过40字的单句？（拆开）
[ ] 被动语态是否过多？（>20%需要改）
[ ] 是否用句号给节奏留白？

【诚实】
[ ] 是否主动标注了局限性？
[ ] 不确定性是否有精确分级（而非笼统的"可能"）？
[ ] 批判性判断是否有依据（而非情绪）？

【个人印记】
[ ] 有没有你特有的比喻或概念封装？
[ ] 是否保持了你的批判锋利度？
[ ] 有没有因追求"全面"而稀释了核心判断？
```

## 附录：你的批判性概念封装（原创表达）

这些是你独有的概念武器，AI不会这样表达：

```
✓ "计量修辞学" —— 描述用复杂统计包装薄弱因果推断的现象
✓ "倒果为因" —— 直接指出因果方向错误的批判词
✓ "路灯下找钥匙" —— 描述方法论选择偏离实际问题本质
✓ "用后视镜开车" —— 形容用历史数据预测未来的方法论局限
✓ "近似校准而非精确拟合" —— 自我标注模型的精确性边界
✓ "在物理上不可成立" —— 对不符合第一性原理的模型结论的极端否定
✓ "方向一致，量级因方法差异而异" —— 你的标准不确定性声明格式
✓ "这是约束来源而非方法缺陷" —— 区分数据问题与模型问题的精准表述
```
