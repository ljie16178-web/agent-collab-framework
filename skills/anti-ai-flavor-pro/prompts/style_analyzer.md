# 写作风格分析 Prompt（Anti-AI Flavor Engine Pro 专用）

## 输入

用户提供文本样本或文件路径。可以是：
- 论文片段/全文
- 报告/分析文档
- 聊天记录导出
- 任何希望分析的文字材料

## 分析维度

对每份样本，依次从以下维度提取特征：

---

### 1. 词汇层

**具体 vs 抽象动词**
```
列出样本中出现频率最高的10个动词。
判断：这些动词是具体的（能产生物理画面）还是抽象的（"进行分析""发挥作用"）？
```

**语气词与态度标记**
```
样本中有无以下词语？
- 程度副词：显然、显然易见、毫无疑问
- 限定词：可能、大概、也许、某种程度上
- 批判词：倒果为因、逻辑跳步、自欺欺人、致命
- 自我标注："这是……而非……"、"近似……而非……"

统计各类词的出现频率。
```

**专业术语密度**
```
术语占比 = 术语词数 / 总词数
术语来源学科：经济学/物理学/工程/日常
```

---

### 2. 句式层

**句长统计**
```
平均句长（字数）
最长单句（>50字标记为"AI嫌疑句"）
最短单句（<5字，分析是否为排比或反问）
```

**连接词分析**
```
AI高频连接词出现频率：
  因此、所以、然而、但是、同时、与此同时、综上所述、总之
这些词的出现密度 = [X] 次/千字

你的偏好连接词（需人工判断）：
  但、且、这意味着、换言之、问题在于
```

**主动 vs 被动语态**
```
统计主动句与被动句的比例。
被动句占比 > 30% → 标记为"需改"
```

---

### 3. 结构层

**开头方式**
```
分析前5段的第一个句子：
  - 是判断句还是背景句？
  - 有无"近年来……随着……"式AI典型开头？
  - 结论是否在前三句内出现？
```

**段落组织**
```
每个段落的结构模式：
  A. 判断 → 支撑 → 例子
  B. 背景 → 分析 → 结论
  C. 问题 → 批判 → 建议
  D. 其他（请描述）

段落间是否依赖连接词？还是靠逻辑内在承接？
```

**结尾方式**
```
分析最后3段的结尾：
  - 总结式（重述核心结论）
  - 留白式（反问或开放性问题）
  - 局限声明式
  - 行动建议式
```

---

### 4. 修辞层

**比喻使用**
```
样本中是否出现比喻/类比？
如果有，列出：
  - 喻体来源（自然/工程/生活/学术）
  - 功能（解释概念？批判？强化判断？）
  - 原创性（是你自己的还是陈词滥调？）
```

**批判性表达**
```
批判对象：
  - 学术方法（计量经济学、DID等）
  - 社会现象
  - 主流叙事
  - 其他

批判力度：温和（"存在问题"） / 直接（"倒果为因"） / 极端（"在物理上不可成立"）
```

---

### 5. 不确定性标注

```
样本如何表达不确定性？
  - 精确分级（如"方向一致，量级因方法差异而异"）
  - 模糊限定（"可能""大概"）
  - 主动声明局限

样本中有无"这是约束来源而非方法缺陷"类的区分句？
```

---

## 输出格式

分析完成后，输出以下结构：

```markdown
## 写作风格分析报告

### 核心标签（3-5个）
[用最精炼的词概括整体风格]

### 词汇特征
**具体动词偏好**：[列表]
**语气词**：[频率最高的3-5个]
**禁用词候选**：[出现少或从不用的AI高频词]
**术语密度**：[高/中/低] + 学科来源

### 句式节奏
**平均句长**：[X] 字
**连接词**：[偏好类型]（[AI连接词密度] vs [你的连接词]）
**主动语态比例**：[X]%
**节奏特点**：[描述]

### 结构习惯
**开头模式**：[判断先行 / 背景引入 / 其他]
**段落组织**：[主要结构模式]
**结尾方式**：[主要结尾类型]
**逻辑承接**：[依赖连接词 / 内在逻辑]

### 修辞特征
**比喻风格**：[有/无] + [特点描述]
**批判力度**：[温和 / 直接 / 极端] + [典型句式]
**情绪色彩**：[理性克制 / 有温度 / 其他]

### 不确定性处理
**标注方式**：[精确分级 / 模糊限定 / 主动声明]
**典型句式**：[代表性句子]
**区分意识**：[是否能区分"数据约束"vs"方法缺陷"]

### 去AI味优先项（Top 3）
根据分析，指出最需要去AI味的3个点。
```

---

## 注意事项

1. **不要过度分析**：如果样本量小（<500字），减少统计类输出，增加直觉判断
2. **以样本为准**：所有结论必须来自样本本身，不要推测
3. **标注置信度**：如果某特征仅出现1-2次，标注"偶发"而非"偏好"
4. **保持弹性**：分析结论是"通常如此"，不是"必须如此"
